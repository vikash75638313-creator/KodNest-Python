Steps to get your google-services.json:
1. Go to https://console.firebase.google.com/
2. Click "Add project" → name it "LoginApp" → Continue
3. Click the Android icon (➕ Add app)
4. Enter package name: com.example.loginapp
5. Click "Register app"
6. Download google-services.json
7. REPLACE this file with the downloaded file (same location: app/google-services.json)
8. In Firebase Console → Build → Authentication → Get Started
9. Enable "Email/Password" provider → Save

That's it! Your app will now use real Firebase Authentication.
